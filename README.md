# Imo's Korean Diner - Ordering Web App 🥢

A responsive web application for ordering Korean street food (Gimbap, Ramen, Bunsik, and Rice bowls). Built with vanilla HTML, CSS, and JavaScript as part of a frontend vocational training program.

## 🚀 Features
* **Interactive Menu Categories**: Easy navigation through Gimbap, Ramen & Bunsik, and Rice bowls.
* **Dynamic Shopping Basket**: Add, remove, and adjust quantities of items seamlessly.
* **Delivery & Pickup Options**: Toggle between delivery and pickup with automatic fee calculation and discounts.
* **Responsive Design**: Fully optimized for both desktop and mobile views with a custom mobile drawer navigation and bottom bar.
* **Clean Brand Styling**: Custom color palette and layout structured with pure CSS.

## 🛠️ Built With
* HTML5
* CSS3 (Flexbox, CSS Variables)
* JavaScript (Vanilla)
